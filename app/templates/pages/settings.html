Where your ComfyUI installation keeps its models. Shared by every import — used to check which files you already have and where to save new downloads.

e.g. C:\ComfyUI\models — the folder containing diffusion_models, text_encoders, vae, loras...

Some models (e.g. FLUX.2 Klein 9B) only download after you accept their license on Hugging Face. Accept it on the model's page, then create a read token in your Hugging Face account (Settings → Access Tokens) and paste it here.

        Developer options and experimental features.

        By default, image generation and LM Studio (chat/vision/prompt-assist) take turns so they don't fight over the same GPU on a shared server. Turn this on only if your hardware has enough headroom to run both at once.

        Stricter than the option above: only one job runs at a time across BOTH ComfyUI and LM Studio, in a single shared queue — even two ComfyUI generations from different clients won't overlap. Overrides "Allow ComfyUI and LM Studio to run at the same time" when both are on.
